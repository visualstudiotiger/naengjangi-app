문제

두 가지 익숙한 피로감

또 사거나, 버리거나

냉장고에 뭐가 있는지 몰라 재료를 중복 구매하거나, 유통기한을 넘겨 버리는 일이 매주 반복됩니다.

오늘도 "뭐 먹지"

매일 식사 메뉴를 고민하는 데 드는 피로감이 쌓입니다. 냉장고 문을 열어봐도 답은 잘 나오지 않습니다.

국내에 유사 문제를 다루는 서비스가 이미 여럿 존재한다는 것 자체가, 문제의 실재성을 방증합니다.

비즈니스 모델

수익은 커머스, 비용은 인식

수익 구조

  • 쿠팡파트너스 제휴 커미션 (식품 카테고리 약 2%)
  • 클릭 후 24시간 내 구매 전체에 커미션 인정
  • (확장) 컬리 등 추가 제휴처 비즈니스 협의
  • (확장) 인기 재료 특정 상품 매칭으로 전환율 개선

비용 구조

  • 영수증 OCR API 사용료 (건당 약 1~5원)
  • 서버·인프라, 이미지 저장, 푸시 알림 운영 비용
  • 콩알 상점 아이템 제작·운영 리소스
  • (2단계 이후) LLM 폴백 매칭 API 비용
